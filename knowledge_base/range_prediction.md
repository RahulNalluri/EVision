# EV Range Prediction Knowledge

Range prediction should not rely only on battery percentage. A useful prediction considers live speed, acceleration, braking, drive mode, AC usage, traffic, weather, road type, route distance, charging habits, and past driving behavior.

Current predicted range estimates how far the vehicle can travel if the driver continues with the present behavior and conditions. Optimized predicted range estimates how far the vehicle can travel if the driver follows battery-saving recommendations.

Destination feasibility compares predicted range with remaining route distance. If the arrival buffer is low, the assistant should recommend Eco mode, smoother acceleration, lower cabin load, and a more efficient speed range.
